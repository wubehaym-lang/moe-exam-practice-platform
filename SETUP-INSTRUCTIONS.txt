WHAT THIS DOES
--------------
One computer (admin computer) runs the server.
All 11 computers connect to it through the local network.
Student data is shared — register once, login anywhere.


STEP 1 — INSTALL NODE.JS (do this once only)
--------------------------------------------
1. Go to: https://nodejs.org
2. Download the "LTS" version
3. Install it (click Next, Next, Install)
4. Restart the computer


STEP 2 — SET UP YOUR PROJECT FOLDER
-------------------------------------
Your project folder should look like this:

  webls_v5/
  ├── server.js           ← NEW (from this package)
  ├── package.json        ← NEW (from this package)
  ├── START-SERVER.bat    ← NEW (from this package)
  ├── index.html
  ├── admin.html
  ├── exam.html
  ├── course.html
  ├── register.html
  ├── manage_exams.html
  ├── Change_Password.html
  ├── View.html
  ├── css/
  ├── icon/
  ├── pct/
  └── js/
      ├── api.js          ← NEW (from this package)
      ├── script.js       ← UPDATED (from this package)
      ├── register.js     ← UPDATED (from this package)
      ├── admin-logic.js  ← UPDATED (from this package)
      ├── manage.js       ← UPDATED (from this package)
      ├── mycours.js      ← UPDATED (from this package)
      ├── View.js         ← UPDATED (from this package)
      ├── info.js         ← UPDATED (from this package)
      ├── exam.js         ← UPDATED (from this package)
      └── (other files unchanged)

Copy all NEW and UPDATED files into your project folder,
replacing the old ones.


STEP 3 — ADD api.js TO YOUR HTML PAGES
-----------------------------------------
Open each HTML file and add this line BEFORE any other <script> tag:

  <script src="js/api.js"></script>

Do this for: index.html, admin.html, register.html,
             manage_exams.html, course.html, View.html,
             Change_Password.html


STEP 4 — START THE SERVER
---------------------------
1. Double-click START-SERVER.bat
2. A black window opens — do NOT close it
3. It will show you the IP address, like:
   Other computers: http://192.168.1.5:3000

4. Write that IP address on the board or tell students


STEP 5 — STUDENTS CONNECT
---------------------------
On each of the 11 computers:
1. Open any browser (Chrome, Edge, Firefox)
2. Type the IP address in the address bar:
   http://192.168.1.5:3000
   (use the IP shown in your server window)
3. The platform opens — students login normally


DEFAULT PASSWORDS
-----------------
Admin login:          username: admin    password: 1234
Admin page lock:      1236
(Change these after first login!)


WHAT IS SAVED WHERE
--------------------
db.json          = all student accounts (on admin computer)
sessionStorage   = current logged-in student (per computer tab)

db.json is created automatically when server first starts.
BACK IT UP regularly — it contains all student data!


TROUBLESHOOTING
---------------
Problem: "Cannot connect to server"
Fix: Make sure START-SERVER.bat is running on admin computer
     Make sure all computers are on same network (same WiFi/LAN)

Problem: "Node.js is not installed"  
Fix: Install Node.js from https://nodejs.org

Problem: Students on other computers cannot reach the site
Fix: Check Windows Firewall — allow Node.js through firewall
     Or temporarily disable firewall for the lab session
